# Vocabulary Trainer

本地运行的背单词前端应用。

## 功能

- **背单词**：展示 / 隐藏悬停；按一个或多个 category 抽词；本地美音/英音发音
- **词库**：切换 `data/*.json`；查词 / 加词；按分类顺序浏览（标记词本、发音、编辑英文/中文）
- **词本**：错词本、收藏本（生词本）、简单词（写在词库 JSON 的 0/1 标记里）
- **导出**：可将 `vocabulary.json` 导出为 CSV
- **导入**：在「词本」页手动选择 CSV，整库覆盖写入 `vocabulary.json`

## 启动

```bash
npm install
npm run dev
```

## 数据文件

| 文件 | 说明 |
|---|---|
| `data/*.json` | 词库与词本状态（唯一数据源）。应用内「词库」选项卡可切换文件 |

词库字段：`id, categoryId, category, english, chinese, pos, isWrong, isFavorites, isEasy`。`pos` 为词性；后三列为 `0` / `1`。

`npm run dev` 时，练习中改词本标记会写回当前选中的 `data/*.json`。在「词本」页可导入 / 导出 CSV。

## 快捷键

练习页（背单词）全局快捷键。macOS 用 ⌘，其它系统用 Ctrl。焦点在 `input` / `textarea` / `select` 内时不触发。

| 快捷键 | 作用 |
|---|---|
| **⌘/Ctrl + J**（按住） | 临时偷看英文（仅「单词展示」关闭时） |
| **⌘/Ctrl + U**（按住） | 临时偷看中文（仅「中文展示」关闭时） |
| **⌘/Ctrl + K** | 朗读当前单词 |
| **⌘/Ctrl + ↑** | 上一个单词 |
| **⌘/Ctrl + ↓** | 下一个单词 |
| **字母等可打印键** | 输入答案（无需点输入框） |
| **Backspace** | 删除一个字符 |
| **Escape** | 清空输入，保留结构前缀（如冠词等） |
| **Enter** | 提交：正确则下一词；错误则提示再试 |

说明：

- ⌘J / ⌘U 为**按住偷看**：松开或窗口失焦后隐藏。
- 答案完全正确时会自动前进；此时再按 Enter 也会前进。
- 焦点在按钮上时，Enter / Space 仍留给按钮，不走答题逻辑。
